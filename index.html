기구

아파트 체력단련실 · Protech Sports · 락커 98번

모든 기구는 노란 핀을 원하는 kg 칸에 꽂아 무게를 정합니다. 5kg 단위. 12회째에 2~3회 더 할 수 있는 무게가 적정. 세트 사이 90초 휴식.
1. 레그프레스허벅지·엉덩이
  1. 등을 등받이에 완전히 붙인다. 허리가 뜨면 안 됨
  2. 왼손 옆 레버로 좌석 조절 — 무릎이 90도쯤 접힌 상태가 시작 자세
  3. 발은 발판 가운데, 어깨너비, 발 전체가 판에 닿게
  4. 밀 때 무릎을 끝까지 펴서 잠그지 않는다
좌석이 너무 앞이면 허리가 말립니다 → 좌석을 뒤로.
2. 랫풀다운등 전체
  1. 허벅지 패드를 다리가 눌리는 높이로 (안 맞으면 몸이 딸려 올라감)
  2. 바를 어깨보다 넓게 잡기
  3. 가슴 위쪽까지 당긴다. 목 뒤로 절대 넘기지 않는다
  4. 팔이 아니라 겨드랑이·등으로 당긴다는 느낌
3. 체스트프레스가슴
  1. 좌석 옆 검은 노브로 의자 높이 조절 — 가로 손잡이가 가슴 한가운데
  2. 아래 페달을 밟으면 손잡이가 앞으로 나온다
  3. 가로 손잡이를 잡는다 (세로는 팔 뒤쪽용)
  4. 팔을 끝까지 쭉 펴지 말고 살짝 굽힌 상태에서 멈춘다
4. 레그컬허벅지 뒤쪽
  1. 엎드려 눕는다
  2. 발목 패드가 발뒤꿈치 바로 위에 오게
  3. 발뒤꿈치를 엉덩이 쪽으로 당긴다
  4. 허리가 들리지 않게 배에 힘
레그컬 대신 레그익스텐션
레그컬을 누가 쓰고 있으면 기다리지 말고 레그익스텐션으로 바꾸세요. 오늘 화면의 4번 종목에서 전환 버튼을 누르면 됩니다. 무게는 15kg부터.
  1. 앉아서 등을 등받이에 붙이고 발목 패드를 정강이 아래에 맞춘다
  2. 무릎을 천천히 펴서 1초 멈춘다
  3. 반동을 쓰지 말고 천천히 내린다
  4. 무릎이 아프면 끝까지 펴지 말고 살짝 덜 편 상태에서 멈춘다

표는 목표일 뿐 규칙이 아닙니다. 12회가 버거우면 그 주 무게를 유지하세요. 올리는 것보다 계속 나가는 게 중요합니다.

이어폰을 끼고 폰을 기구 옆에 세워두세요. 음성이 횟수를 세고 세트 사이 90초를 재줍니다. 끝난 세트는 오늘 기록에 자동으로 체크됩니다.

집에서 10분

체력단련실에 못 갈 때. 기구 없이 집에서. 층간소음 없는 동작만 골랐습니다. 발목·무릎을 잡아주는 관절 운동도 들어 있습니다. 시간이 없으면 "짧게"를 고르세요.
